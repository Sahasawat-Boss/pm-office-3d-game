## 🟢 Quick win (< ครึ่งวัน)

- **คีย์ลัดเพิ่ม**
  - ตอนนี้มีแค่ Space ไว้หยุดเกม ([main.js:488](../../src/main.js#L488)) แต่มีปุ่ม speed (`data-sp`) และ `#autoBtn` อยู่แล้ว
  - เพิ่ม `1/2/3` = เปลี่ยนความเร็ว, `A` = แจกงานอัตโนมัติ, `O` = เปิด/ปิด OT, `Esc` = ยกเลิกการเลือก ช่วยให้เล่นด่านยากที่ต้องตัดสินใจถี่ได้ลื่นขึ้น
  - ไฟล์: `src/main.js` (keydown handler), `index.html` (tooltip) — effort S
- **ปลดล็อกด่านตามลำดับ**
  - `showStart()` เปิดให้เล่นทั้ง 7 ด่านตั้งแต่แรก แม้จะมีระดับ ง่าย→โหด (`diff`/`dcol` ใน `levels.js`)
  - ให้ด่านถัดไปปลดล็อกเมื่อมี `SAVE.best` ของด่านก่อนหน้า ใช้ข้อมูลเดิมได้เลย ไม่ต้องแก้ save format และทำให้ป้าย "ผ่านด่าน" ที่เพิ่งเพิ่มมีความหมายขึ้น
  - ไฟล์: `src/main.js` (`showStart`), `src/style.css` (`.lv.locked`) — effort S
- **สมุดบทเรียนในหน้าเริ่ม**
  - `EVENTS` มี `lesson` 10 แบบ และเก็บลง `S.lessons` ([main.js:686](../../src/main.js#L686)) แต่ใช้แค่ในหน้าจบด่านแล้วหายไป
  - ให้เก็บบทเรียนที่เคยเจอลง `SAVE.lessons` แล้วเพิ่มแท็บ "📚 บทเรียน PM" ข้าง "อัปเกรดออฟฟิศ" ให้คนเล่นได้ทวนสิ่งที่เรียนรู้ เพราะเป้าของเกมคือสอน PM
  - ไฟล์: `src/main.js` (SAVE, `addLesson`, `setTab`), `index.html` (tab) — effort S

## 🔥 Impact สูง

- **ไฮไลต์ Critical Path บน Kanban**
  - ด่าน ERP เขียนว่า "ต้องหา Critical Path ให้เจอ" และงานมี `dep` ครบ แต่ UI แสดงแค่ 🔒 blocked ([main.js:944](../../src/main.js#L944)) ผู้เล่นต้องไล่ dependency เอง
  - ให้คำนวณ longest path จาก `effort` + `dep` ตอน `newGame` และทุกครั้งที่งานเสร็จ แล้วใส่ขอบ/ไอคอน 🔴 ให้การ์ดที่อยู่บน path เปิด-ปิดได้ เพื่อสอนแนวคิด CPM โดยตรง
  - ไฟล์: `src/main.js` (ฟังก์ชันใหม่ `criticalPath()`, render card), `src/style.css` — effort M
- **Tutorial แบบ guided ในด่านแรก**
  - ตอนนี้มีแค่กล่อง `.how` 4 ข้อในหน้าเริ่ม ซึ่งถูกซ่อนตอนอยู่ใน shop mode และไม่มีขั้นตอนพาเล่น
  - ด่าน `cafe` มีงานแค่ 8 ชิ้น เหมาะทำ step-by-step ไปทีละขั้น: คลิกการ์ด → กดชื่อคน → กด ▶ → ดูวงความเครียด → ลอง 1:1 ทำได้ด้วย `hint()` และ highlight element ที่มีอยู่แล้ว
  - ไฟล์: `src/main.js` (state `S.tut`), `src/style.css` — effort M
- **Daily stand-up summary**
  - ตอนนี้ log อยู่ใน `S.log` และ `mark()` เก็บเหตุการณ์ไว้แค่ไปใช้ใน burndown ตอนจบ
  - เพิ่ม toast สั้นๆ ทุกต้นวัน เช่น "เมื่อวาน เสร็จ 2 งาน / ว่าง 1.5 วัน-คน / งบเกินแผน 8%" ให้ผู้เล่นรู้สัญญาณเตือนก่อนจบด่าน (insight ตอนนี้มาตอนจบเท่านั้น)

  - ไฟล์: `src/main.js` (`sim` ตอนเปลี่ยนวัน) — effort M
